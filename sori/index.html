오늘의 음악 용어

정리 단계 판서용

이렇게 해 보세요

  1. 주문서를 하나 고릅니다. (예: 졸린 자장가)
  2. 기본 맛 듣기를 먼저 누릅니다. 아무 양념도 넣지 않은 소리예요.
  3. 양념 선반에서 빠르기·셈여림·이음과 끊음·악기를 바꿉니다.
  4. 내 요리 듣기 → 번갈아 듣기로 두 소리를 견주어 들으며 무엇이 달라졌는지 찾습니다.
  5. 마음에 들면 코드를 적어 두고, 친구와 바꿔 들어 봅니다.

주문서에 정답은 없습니다. 친구에게 들려주고 어떤 주문서였는지 맞혀 보게 하세요. 선생님 화면에는 활동 1용 귀 열기 퀴즈와 활동 3용 모둠 코드 모아 듣기가 있습니다.
