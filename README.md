# 초등 음악 수업 웹앱

2022 개정 음악과 교육과정에 맞춘 초등 음악 수업용 웹앱 두 가지입니다.
바이브 코딩으로 제작했으며, 회원가입·로그인·개인정보 입력 없이 주소만으로 작동합니다.

| 앱 | 대상 | 영역 | 성취기준 |
|---|---|---|---|
| **소리 요리사** (`/sori/`) | 4학년 | 서양음악 · 감상/창작 | [4음02-01] [4음03-02] |
| **덩덕쿵 공방** (`/jangdan/`) | 5학년 | 국악 · 창작/연주 | [6음03-02] [6음01-03] |

## 공통 설계

- 소리는 Web Audio API로 **브라우저에서 합성**합니다. 외부 음원 파일이 없습니다.
- 모둠 결과는 **네 글자 코드**로 주고받습니다. 서버로 전송하거나 저장하는 자료가 없습니다.
- 각 앱은 **학생 화면**과 **선생님 화면**으로 나뉩니다. 선생님 화면에는 듣고 맞히는 퀴즈와 모둠 결과를 모아 듣는 기능이 있습니다.
- 단일 HTML 파일이라 내려받으면 인터넷 없이도 열립니다. (글꼴만 구글 폰트에서 받아오며, 막혀도 기기 글꼴로 대체되어 기능은 그대로입니다.)

## 자료 출처

- 서양 제재곡: 작은 별(프랑스 민요), 환희의 송가(베토벤, 1824), 메리의 어린 양(미국 동요, 1830) — 모두 저작권 소멸.
- 국악 장단: 굿거리·자진모리·세마치. 교과서에서 널리 쓰이는 기본 꼴을 따랐으며, 지역과 악곡에 따라 다른 꼴도 있습니다.
- 아이콘: 모두 직접 그린 SVG.
